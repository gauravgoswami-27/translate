# Training on Kaggle

## One-time setup
1. **Hugging Face:** log in and accept the terms (access is approved automatically) on:
   - https://huggingface.co/ai4bharat/indictrans2-en-indic-dist-200M
   - https://huggingface.co/ai4bharat/indictrans2-en-indic-1B
   - https://huggingface.co/datasets/ai4bharat/IN22-Gen

   Then create a **read** token under Settings → Access Tokens.
2. **Build the bundle** locally, from the repo root:
   ```bash
   bash kaggle/make_bundle.sh      # -> kaggle/dist/vocational-nmt-bundle.zip (~42 MB: code, corpus incl. drafts, glossary, run-4 adapter)
   ```
3. **Kaggle → Datasets → New Dataset:** upload `vocational-nmt-bundle.zip`. Keep it **Private**, because the NIMI CITS books are marked "not to be republished".

## Notebooks
- `run4_raw_distillation.ipynb`: run 4 (drafts → joint LoRA on raw drafts → evaluation). Kept for reproducibility (git tag `v1-raw-distillation`).
- `run7_seed_rank.ipynb`: run 7 (third seed of the main model; Hindi-only LoRA rank sweep). Generated by `build_run7_notebook.py`.
- `run6_case_fixed.ipynb`: run 6 (retraining on the case-fixed formal drafts; seed-43 replicate and Hindi-only ablation on the second GPU). Generated by `build_run6_notebook.py`. No translation of training data.
- `run5_terminology_aware.ipynb`: run 5 / experiment 2 (terminology repair of drafts → `joint_formal` LoRA → evaluation of all systems, with and without constrained decoding). The bundle contains the raw drafts and the run-4 adapter, so no other inputs are needed.

## Each run
1. Kaggle → New Notebook → File → Import Notebook → pick the notebook for the run.
2. In the right panel:
   - **Add Input:** your bundle dataset.
   - **Accelerator:** GPU T4 x2.
   - **Internet:** On.
   - **Add-ons → Secrets:** `HF_TOKEN` = your token, with notebook access enabled.
3. Run cells 1-4 interactively (setup and smoke tests, about 5-10 minutes; in run 5, cell 4 prints 5 repaired drafts, so check they read sensibly). If they pass, use **Save Version → Save & Run All**.
4. When it finishes, download `outputs.zip` from the version's Output tab and unzip it locally:
   - `corpus_v2/` → `backend/data/corpus_v2/`
   - `it2_lora_joint*/` → `backend/models/`
   - `results/` → `backend/results/`
   - archive the zip and the log under `kaggle/runs/<date>_<run>/` (git-ignored)

Expected time is about 3-4 hours per run, within Kaggle's 12-hour session limit and the 30 GPU-hours weekly quota. Drafts are written per language and skipped on re-run, so a crashed session can resume.

## After post-editing
Put the filled sheets in `backend/data/corpus_v2/postedit/` and re-score the saved predictions locally. This needs only the CPU, no Kaggle run:
```bash
python -m backend.run_domain_eval --from-predictions backend/results/domain_predictions_UNVERIFIED_run5.csv \
    --require-human-refs --tag run5
```
