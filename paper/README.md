# paper/

- `OBSERVATIONS.md`: findings, numbers and their sources, marked [final] or [provisional]. Update it after every run.
- `METHODOLOGY.md`: full experimental setup and replication guide (data, models, hyperparameters, evaluation, software versions, commands, run registry). Update it with every change to settings or runs.
- `DATA_SOURCES.md`: ledger of all resources (source books, models, benchmark, glossary references, derived datasets, compute). Update it with every new resource or run.
- `references.bib`: bibliography; the keys are cited in OBSERVATIONS.md. Verify every entry before submission.

- `ieee/`: the IEEE conference paper (LaTeX source, figures, figure script, its own `references.bib`). See `ieee/README.md` for the build.

The draft is based on run 6 and the four original languages. Glossary review was skipped by decision and is stated as a limitation. Domain scores are against unedited teacher drafts until the test sets are post-edited.
